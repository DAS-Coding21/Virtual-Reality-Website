# Virtual-Reality-Website
Build a responsive VR (Virtual Reality) E-commerce website.

A responsive Virtual Reality (VR) e-commerce website built using **HTML5, CSS3 and Bootstrap 5.3.9**. This project showcases VR products, kit components, product features and other sections through a clean, modern user interface.

## ✨ Features

- **Responsive Navigation Bar** – Navigate between different website sections.
- **Hero Section** – Introduces the virtual reality experience.
- **Features Section** – Highlights the features and capabilities of VR.
- **Included VR Kit** – Showcases the headset, touch controllers and charging cable.
- **Products Section** – Displays VR products with descriptions and prices.
- **Optics and Controllers** – Presents information about VR optics and controllers.
- **Contact Section** – Includes a interface to contact with us.
- **Trending Blogs** – Displays featured blog content.
- **Footer Section** – Provides additional website information and contact details.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.9
- Bootstrap Grid System
- CSS Media Queries

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/DAS-Coding21/Virtual-Reality-Website.git
   ```

2. Open the project folder:

   ```bash
   cd Virtual-Reality-Website
   ```

3. Open `index.html` in your browser.

   Alternatively, open the project in Visual Studio Code and run it using the Live Server extension.

## 📱 Responsive Design

The website uses Bootstrap's grid system and CSS media queries to adapt its layout to different screen sizes:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

## 🎯 Project Objective

The objective of this project was to practice frontend web development by building a multi-section e-commerce website, working with Bootstrap components, organizing website assets and creating responsive layouts.
